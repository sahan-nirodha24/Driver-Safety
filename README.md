# Driver Safety

This comprehensive Android application is designed to enhance driver safety by leveraging intelligent features and modern development practices, including secure user authentication (login, signup, and password recovery) to deliver a personalized, accident-prevention-focused experience.

## Features

Based on the project's source code, the application includes the following features:

*   **User Authentication:**
    *   **Login:** Existing users can log in to their accounts. (`login.kt`)
    *   **Signup:** New users can create an account. (`signup.kt`)
    *   **Forgot Password:** Users can recover their password. (`forget_password.kt`)
*   **Main Dashboard:** A central hub for accessing the app's features. (`Dashboard.kt`)
*   **Driver Diagnosis:** A feature to assess the driver's condition, potentially checking for fatigue or other factors affecting driving ability. (`Diagnosis.kt`)
*   **Rest Stop Locator:** Helps drivers find nearby rest stops to take breaks during long journeys. (`RestStops.kt`)
*   **Smart Assistant:** An in-app assistant to help with tasks without distracting the driver. (`SmartAssistant.kt`)
*   **User Profile:** Users can manage their profile information. (`Profile.kt`)
*   **Splash Screen:** A startup screen for the application. (`spalsh.kt`)

## Project Structure

The project follows a standard Android application structure. The core features are implemented in Kotlin under the `com.example.driversafety` package.

## Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

*   Android Studio
*   A device or emulator running Android

### Installation

1.  Clone the repo
    ```sh
    git clone <your-repository-url>
    ```
2.  Open the project in Android Studio.
3.  Build the project and run it on an emulator or a physical device.
