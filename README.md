# 🚗Driver Safety

This comprehensive Android application is designed to enhance driver safety by leveraging intelligent features and modern development practices, including secure user authentication (login, signup, and password recovery) to deliver a personalized, accident-prevention-focused experience.

## ✨ Features

- **🔑 User Authentication**
  - **Login:** Existing users can securely log in to their accounts. (`login.kt`)
  - **Signup:** New users can create an account. (`signup.kt`)
  - **Forgot Password:** Users can recover their password if forgotten. (`forget_password.kt`)

- **🏠 Main Dashboard**
  - A central hub for accessing all app features. (`Dashboard.kt`)

- **🩺 Driver Diagnosis**
  - Assesses the driver's condition, helping detect fatigue or other factors affecting driving ability. (`Diagnosis.kt`)

- **🛑 Rest Stop Locator**
  - Helps drivers find nearby rest stops to take breaks during long journeys. (`RestStops.kt`)

- **🤖 Smart Assistant**
  - An in-app assistant that allows hands-free interaction to reduce distractions while driving. (`SmartAssistant.kt`)

- **👤 User Profile**
  - Users can view and manage their profile information. (`Profile.kt`)

- **🚀 Splash Screen**
  - A startup screen displayed when the app launches. (`splash.kt`)


## 🚀 Project Structure

The project follows a standard Android application structure. The core features are implemented in Kotlin under the `com.example.driversafety` package.

```DriverSafetyApp/```

```│```

```└── splash.kt # Splash screen shown at app startup```

```├── login.kt # Login functionality for existing users```

```├── signup.kt # Signup functionality for new users```

```├── forget_password.kt # Password recovery feature```

```├── Dashboard.kt # Main dashboard, central hub for features```

```├── Diagnosis.kt # Driver condition assessment feature```

```├── RestStops.kt # Rest Stop Locator for long journeys```

```├── SmartAssistant.kt # In-app smart assistant for hands-free operation```

```├── Profile.kt # User profile management```


### Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

*   Android Studio
*   A device or emulator running Android

### Installation

1.  Clone the repo
    ```sh
    git clone <your-repository-url>
    ```
2.  Open the project in Android Studio.
3.  Build the project and run it on an emulator or a physical device.
